# The Only One Who Enforces My Screen Time

Entry for [The One-Line Cat Joke That Lands](https://make.fun/c/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262) on make.fun.

One joke about cats: a single line, under 200 characters. The cat sits on
my phone, knocks it off the table when I reach for it — and turns out to be
the only one in the house who enforces my screen time.

## The joke

> My cat sat on my phone, then knocked it off the table when I reached for it — she's the only one in this house who enforces my screen time.

## Run

```
python3 main.py
```

Writes the joke to `/output/entry.txt` (139 characters, one line, no
trailing newline) and prints the character count.
